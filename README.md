# カタン入門 — 카탄 게임 서바이벌 가이드

내일 일본 사람들과의 카탄을 앞두고, 룰·자원 이름·교역 문장을 **한/일 병기**로 약 3시간 만에 학습하는 인터랙티브 웹 가이드. (`../shogi`와 같은 구조)

## 실행

```bash
npm install
npm run dev
# → http://localhost:5173
```

## 구성

| 모듈 | 내용 | 분량 |
|---|---|---|
| 1 | 카탄 첫걸음 — 승리 조건(승점 10점), 턴 3단계, 초기 배치 | 25분 |
| 2 | 자원 & 지형 마스터 — 5대 자원 일본어, 인터랙티브 육각 보드, 주사위 확률, 플래시카드 | 35분 |
| 3 | 건설 & 배치 룰 — 비용표, 間隔ルール, 초기 배치 요령 | 30분 |
| 4 | 도둑·교역·발전 카드 — 7의 처리, 항구, 발전 카드 5종, +2점 타이틀 | 35분 |
| 5 | 게임 서바이벌 일본어 — 인사·턴·교역·도둑·리액션 문장 40+개 | 50분 |
| 6 | 종합 복습 — 통합 퀴즈, 오답 노트, 게임 직전 5분 컨닝페이퍼 | 25분 |
